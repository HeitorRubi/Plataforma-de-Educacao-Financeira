# Plataforma de Educação Financeira

Projeto de Trabalho de Graduação desenvolvido em etapas bloqueadas. Esta versão
contém somente o ambiente base da aplicação.

## Tecnologias desta etapa

- Next.js com App Router
- React
- TypeScript
- Tailwind CSS
- ESLint

## Executar localmente

Instale as dependências:

```powershell
npm.cmd install
```

Inicie o servidor de desenvolvimento:

```powershell
npm.cmd run dev
```

Abra [http://localhost:3000](http://localhost:3000) no navegador.

## Verificações

```powershell
npm.cmd run lint
npm.cmd run build
```

No PowerShell deste computador, utiliza-se `npm.cmd` porque a política de
execução do Windows bloqueia o script `npm.ps1` chamado pelo comando `npm`.
